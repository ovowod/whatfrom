- CLI module의 import와 API 서버는 PyYAML 없이 동작한다.
- golden set을 읽는 명령, 즉 `eval`과 `load-questions`를 실행할 때만 dev 의존성인 PyYAML이 필요하다.

- [ ] 계층 규칙 설명(다른 stage를 직접 참조하지 않음)은 그대로 남는다.

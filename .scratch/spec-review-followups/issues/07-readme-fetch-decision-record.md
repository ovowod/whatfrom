**Desired behavior:**
`docs/adr/0001-readme-from-docker-library-docs.md`를 만든다. 내용은 다음과 같다.
- 맥락: Docker Hub `full_description`은 25,000자에서 잘린다. 그래서 postgres의 Image Variants 절이 빠지고 eclipse-temurin의 태그 목록이 줄어든다.

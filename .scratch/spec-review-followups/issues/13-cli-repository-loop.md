## Agent Brief

**Category:** enhancement
**Summary:** CLI의 collect/derive/index 명령에 반복된 "repository 목록 결정 + 실패 격리 루프 + parser group"을 한 번만 정의한다.

**Current behavior:**
세 명령이 같은 코드를 각자 반복한다.
- `OFFICIAL_REPOSITORIES if args.all else (args.repository,)`로 대상을 정한다.
- derive와 index는 실패 시 `failed += 1`을 하고 `"{repository:<16} failed: ..."`를 출력한 뒤, 마지막에 `1 if failed else 0`을 돌려주는 루프를 반복한다.
- `repository | --all` 필수 mutually exclusive group 정의도 세 번 복제돼 있다.

**Desired behavior:**
대상 결정, 실패 격리와 종료 코드 계산, parser group 추가를 각각 한 곳에서 정의하고, 세 명령이 그것을 쓴다. 출력 형식, 종료 코드, CLI 인자는 byte 단위로 그대로 유지한다.

**Key interfaces:**
- `collect`, `derive`, `index` subcommand의 인자(`repository` 위치 인자, `--all`)와 종료 코드 계약.
- 실패한 repository가 하나라도 있으면 나머지를 계속 처리하고, 끝에 종료 코드 1을 돌려준다.

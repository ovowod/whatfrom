# Docker Hub client가 5xx 일부만 재시도한다

Status: wontfix
Source: Spec 리뷰 — `docs/superpowers/specs/2026-09-14-collection-expansion-design.md`

## 문제

spec은 "5xx | 지수 백오프 + jitter로 재시도"라고 적었다. 그런데 `RETRY_STATUSES`는 `{429, 500, 502, 503, 504}`뿐이라, 501, 505 같은 나머지 5xx는 곧바로 `HTTPStatusError`가 된다.

다만 501(Not Implemented)과 505는 다시 보내도 결과가 바뀌지 않는다. 그래서 코드를 고칠 일이 아니라 spec 문구를 고칠 일일 수도 있다.

## 위치

- `src/whatfrom/collect/hub.py:18`

## 완료 조건

다음 둘 중 하나를 고르고, 테스트나 spec을 그에 맞춘다.

- 모든 5xx를 재시도한다.
- spec 문구를 "500, 502, 503, 504"로 고친다.

**Summary:** spec이 요구했지만 빠진 테스트 두 개를 추가한다.

**Current behavior:**

2. tag-parser spec은 파생 값이 NULL인 태그로 만든 `Candidate`의 파생 필드(version, distro, codename, variant)도 None인지 확인하라고 했다. 하지만 기존 테스트는 DB 컬럼까지만 확인한다.

**Desired behavior:**
두 동작을 테스트로 고정한다. production 코드는 바꾸지 않는다.

**Key interfaces:**
- `timed_recommendation`과 그 결과인 `RunTrace`(단계별 `seconds_*`, `advise_prompt`)
- 검색 결과 `Candidate`의 파생 필드

**Acceptance criteria:**

- [ ] 새 테스트는 현재 코드에서 통과한다. 의도적으로 동작을 깨뜨리면 실패하는지도 한 번 확인한다.

**Out of scope:**
- production 코드 변경.
- 다른 테스트 정리나 재배치.

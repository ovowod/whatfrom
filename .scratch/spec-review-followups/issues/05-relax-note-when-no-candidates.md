# 후보가 0개일 때 "조건을 풀었다" 알림이 함께 나간다

Status: done
Category: bug

## 문제

조건을 모두 풀어도 후보가 0개인 경우가 있다. 이때 `search_candidates_with_plan`은 "조건에 맞는 태그가 없어 …을 풀었습니다"를 notes에 넣는다. 이어서 `api.py`가 "검색된 후보가 없습니다"를 덧붙인다. 결국 사용자는 효과가 없었던 완화를 안내받는다. spec 위반은 아니지만 응답이 오해를 부른다.

## Agent Brief

**Category:** bug
**Summary:** 조건을 모두 풀어도 후보가 없으면 "조건을 풀었다"는 알림을 내지 않는다.

**Current behavior:**
`search_candidates_with_plan`은 완화 단계를 거치며 풀어 본 조건을 모은다. 후보가 끝내 0개여도 "조건에 맞는 태그가 없어 …을 풀었습니다" 알림을 notes에 넣는다. 그 위에 추천 경로가 "검색된 후보가 없습니다…"를 덧붙여, 사용자는 효과가 없었던 완화를 안내받는다.

**Desired behavior:**
조건 완화로 후보를 실제로 얻었을 때만 완화 알림을 낸다. 완화해도 후보가 없으면 완화 알림 없이 "검색된 후보가 없습니다" 안내만 남는다. 이 경우에도 응답의 `degraded`는 지금처럼 true로 둔다.

**Key interfaces:**
- `search_candidates_with_plan`의 반환값(`candidates`, `notes`, `degraded`): 반환 구조는 바꾸지 않는다.
- `RecommendResponse.notes`

**Acceptance criteria:**
- [ ] 모든 완화 단계에서 후보가 0개면 `notes`에 "풀었습니다" 문구가 없다.
- [ ] 완화로 후보를 얻은 경우의 알림은 기존과 같다.
- [ ] 후보 0개일 때 API 응답의 `degraded`는 true다.
- [ ] 위 두 경우를 각각 검증하는 테스트가 있다.

**Out of scope:**
- 완화 순서나 알림 문구 변경.
- "검색된 후보가 없습니다" 문구 변경.

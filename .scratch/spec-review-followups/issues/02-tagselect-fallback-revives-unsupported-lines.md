# 지원 줄기의 별칭이 모두 빠지면 폴백이 지원 끝난 줄기를 되살린다

Status: done
Category: bug
Source: Spec 리뷰 — `docs/superpowers/specs/2026-09-17-release-line-candidates-design.md` §3.3, §3.4, §3.6

## 문제

spec의 해당 규칙은 다음과 같다.

- §3.4: "지원 줄기가 하나만 남아도 그대로 쓴다. 폴백으로 가지 않는다"
- §3.6: 폴백은 "별칭 줄기를 찾지 못하면" 쓴다.
- docstring: "폴백은 리포지토리 전체의 성질로만 정한다"

코드는 줄기 단위(`depth`)를 찾은 경우에도 폴백한다. `_supported_aliases`의 결과(`kept`)가 비면 `_by_recent_push(stable)`로 넘어간다. 지원 줄기의 별칭이 모두 낡은 변형으로 빠지면 `kept`가 빈다. 그러면 지원이 끝난 줄기의 태그가 다시 후보에 들어오는데, §3.3이 막으려던 경로다.

## 위치

- `src/whatfrom/search/tagselect.py:91-93`

## 완료 조건

- `depth`가 있고 `kept`만 빈 경우를 재현하는 테스트를 만든다.
- 그 경우의 기대 동작을 정한다(빈 결과 또는 지원 줄기의 고정 태그). 결정에 따라 spec이나 코드를 맞춘다.

## Agent Brief

**Category:** bug
**Summary:** 줄기 단위를 찾았는데 지원 줄기의 별칭이 모두 빠진 경우, 폴백 범위를 지원 줄기의 태그로 제한한다.

**Current behavior:**
`select_tags`는 줄기 단위(depth)를 찾은 뒤 지원 줄기의 별칭을 고른다. 지원 줄기 판정에는 `pinned_version`으로 되살린 줄기도 들어간다. 이때 별칭이 모두 낡은 변형으로 빠지면 결과가 빈다. 낡은 변형은 줄기의 가장 최근 푸시보다 SUPPORT_GAP 넘게 뒤처진 별칭이다. 결과가 비면 repository의 안정 태그 전체에서 최근 푸시 순으로 고르는 폴백으로 넘어가고, 지원이 끝난 줄기의 태그가 되살아난다. 이런 일은 줄기의 고정 태그(`3.14.7`)는 최근에 푸시됐지만 이동 별칭(`3.14`)이 갱신되지 않을 때 생긴다.

**Desired behavior:**
줄기 단위가 정해졌으면, 지원 줄기의 별칭이 모두 빠져도 지원 줄기에 속한 안정 태그(고정 태그 포함) 안에서만 고른다. 처리 순서는 기존 코드와 같게 "지원 줄기로 거르기 → `allowed_ids`로 거르기 → 같은 digest 접기 → 최근 푸시 순 정렬·limit"으로 한다. 접은 뒤에 거르면, 허용된 긴 이름이 허용되지 않은 짧은 이름에 흡수돼 함께 사라진다. 지원이 끝난 줄기의 태그는 결과에 나오지 않는다. 단, `pinned_version`으로 되살린 줄기는 예외로 나올 수 있다. 줄기 단위를 찾지 못한 경우(depth가 None)의 폴백은 지금 그대로 둔다. "폴백은 리포지토리 전체의 성질로만 정한다"는 docstring은 이 동작에 맞게 고친다.

**Key interfaces:**
- `select_tags(tags, limit, allowed_ids, pinned_version)`: signature는 바꾸지 않는다.
- 지원 줄기 판정(`SUPPORT_GAP`, pinned 되살리기) 규칙은 바꾸지 않는다.

**Acceptance criteria:**
- [ ] 지원 줄기 하나와 지원이 끝난 줄기 하나가 있고, 지원 줄기의 별칭만 낡은 경우를 테스트한다. 결과에 지원 줄기의 고정 태그가 나오고, 지원이 끝난 줄기의 태그는 없다.
- [ ] 새 폴백에서 같은 digest를 가리키는 두 태그 중 긴 이름만 허용된 경우, 그 태그가 결과에 남는 회귀 테스트가 있다.
- [ ] depth가 None인 repository의 결과는 바뀌지 않는다.
- [ ] 기존 tagselect 테스트와 `make eval-retrieval`의 지표가 나빠지지 않는다.

**Out of scope:**
- Windows 전용 태그의 digest 전파(issue 01).
- SUPPORT_GAP 값 변경.

# 02: v2 지표: 인용 검증 통과율, 오답 적발률, 오판정률

**What to build:** eval 요약과 결과 JSON에 design §10의 v2 지표가 나온다. 인용 검증 통과율은 응답 주장들의 인용 전체 중 검증을 통과한 비율이다. 오답 적발률과 오판정률은 후보 단위로 세고, 판정이 없는 실행에서는 미측정이다. 명시적 오답이 후보에 나온 문항 수도 기록한다.

spec: `.scratch/v2-eval/spec.md` (v2 지표)

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 인용 검증 통과율: 분모는 응답 주장들에 붙은 인용 전체, 분자는 검증을 통과한 인용이다. 인용이 0개면 미측정이다.
- [ ] 오답 적발률: 분모는 후보로 나온 명시적 오답, 분자는 그중 불만족 판정을 하나 이상 받은 후보다. 명시적 오답이 후보에 없는 문항은 분모에서 빠진다.
- [ ] 오판정률: 분모는 후보로 나온 허용 정답, 분자는 그중 불만족 판정을 받은 후보다.
- [ ] 집계 함수는 후보별 "불만족 판정을 하나 이상 받았는가"를 입력으로 받는다. 판정이 없는 실행은 두 지표 모두 0%가 아니라 미측정이다.
- [ ] 명시적 오답이 후보에 나온 문항 수가 요약과 결과 JSON에 나온다.
- [ ] 미측정은 기존 `Metric.ratio`의 분모 0 규칙을 따른다.
- [ ] 집계 함수 테스트로 경계 사례를, CLI seam 테스트로 요약과 결과 JSON 출력을 확인한다.
